# Extractors Directory

This directory contains specialized logic for parsing and extracting structured data from unstructured formats (e.g., resumes).

**Purpose:**
- House custom Natural Language Processing (NLP) pipelines using libraries like spaCy.
- Store regex pattern matchers for finding specific data (emails, phone numbers, degrees).
- Contain normalization logic to standardize extracted entities.
- Process PDF/DOCX text into structured JSON data for candidate profiles.

# Models Directory

This directory contains the SQLAlchemy Object-Relational Mapping (ORM) models.

**Purpose:**
- Define the structure of the database tables using Python classes.
- Specify columns, data types, primary keys, and constraints.
- Define relationships (One-to-Many, Many-to-Many) between different entities (e.g., User to JobApplication).

These models are utilized by the `repositories/` to query and manipulate database records in an object-oriented manner.
